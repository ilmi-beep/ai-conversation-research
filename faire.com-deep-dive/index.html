What to fix first

The biggest problems, in the order an AI tool meets them. A tool that cannot reach or read your pages never gets as far as trusting them.

Severity:▲ High fix this quarter■ Medium next template release● Low when the template is next edited

Some pages only show their text after JavaScript runs

Failed check: Your page text is in the page your server sends

▲ High Gate 2: read Error

Why it matters. Many AI crawlers do not run JavaScript. If the text only appears after scripts run, they see an almost empty page.

Fix. Have the server send the page text in the HTML (server-side rendering), so the text does not depend on JavaScript.

What we found, and how you know it is done
  • Brand pages: 1 of 1
  • Company pages: 1 of 1

Examples

  • https://www.faire.com/brands: the server sends almost no text; the page text only appears after JavaScript runs
  • https://www.faire.com/careers: the server sends almost no text; the page text only appears after JavaScript runs

Done when: The main text of each page is in the HTML the server sends.

Effort: A day or less

Your home page does not describe the business and the site in structured data

Failed check: Your home page says in structured data who the business is (Organization) and what the site is called (WebSite)

▲ High Gate 2: read Error

Why it matters. Search engines and AI tools look at the home page first to learn the business's name, logo and profiles (Organization) and the site's name (WebSite). Without them they have to guess.

Fix. Add one Organization block (name, url, logo, sameAs) and one WebSite block (name, url) to the home page.

What we found, and how you know it is done
  • Home page: 1 of 1

Examples

  • https://www.faire.com/: the home page has no Organization (the code that names the business)
  • https://www.faire.com/: the home page has no WebSite (the code that names the site)

Done when: The home page has an Organization block and a WebSite block, each with a name and url.

Effort: A day or less
