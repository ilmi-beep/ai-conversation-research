7 more findings (2 high, 3 medium, 2 low), also listed under each gate below

Aqua Fast Flush is described with types that do not exist, so tools cannot read it

Failed check: Every type in your structured data is a real schema.org type (schema.org is the shared vocabulary search engines and AI read)

■ Medium Gate 2: read Error

Why it matters. Search engines and AI tools only understand terms in the schema.org vocabulary. A type schema.org does not have means nothing to them, so what it describes is not understood. To extend schema.org, use your own namespace (an @context prefix or a full web address) plus additionalType pointing to the nearest schema.org type, and only where schema.org has no type of its own.

Fix. Replace each unknown type and property name with the schema.org term made for it.

What we found, and how you know it is done
  • "DrainExpert" is not a schema.org type.
  • "serviceArea" is a schema.org name, but schema.org has replaced it with areaServed, and it is meant for ContactPoint, organizations and Service.

Examples

  • https://www.aquafastflush.ca/location/commercial-sewer-pipe-cleaning-and-power-flushing-hamilton-high-pressure-drain-cleaning-services-in-hamilton-ontario/: "DrainExpert" is not a schema.org type

Done when: Every type and property name in your structured data is a schema.org term, or sits in your own namespace with additionalType pointing to the nearest schema.org type.
